## B. Bugs fixed

- **P0** Unauthorized remote writes. Preview bypasses status notes, comments, labels and native reviews. The package harness checks for remote writes, and the [pipeline](../src/engine/__tests__/pipeline.test.ts), [watcher](../src/engine/__tests__/watchLoop.test.ts), and [dashboard](../src/tui/__tests__/dashboard.test.ts) tests check authorization.
- **P0** Unanchored findings, malformed responses shown as clean, and provider body disclosure. Regression tests cover wrong files, removed and context lines, missing evidence, wrong shapes, and redacted errors. [Reviewer tests](../src/engine/__tests__/reviewer.test.ts)
- **P0** Runtime dependency exposure. The first production audit reported nine advisories including one critical. The MCP SDK, Zod and affected transitive entries were updated within compatible ranges. The post-change production audit reported zero advisories at audit time. [Lockfile](../package-lock.json)
- **P0** Credential origin mismatch. A saved key or legacy Gemini key could follow an endpoint override to an unrelated service. Credential selection now binds saved keys to the configured origin and requires an explicit credential for an alternate origin. [Config tests](../src/engine/__tests__/config.test.ts)
- **P1** Incomplete and stale forge reviews. Diff pagination, unavailable patches, GitLab rename positions, and changed remote heads have regression coverage. [REST tests](../src/engine/__tests__/forgeRest.test.ts) · [MCP tests](../src/engine/__tests__/forgeMcp.test.ts) · [Pipeline tests](../src/engine/__tests__/pipeline.test.ts)
- **P1** Broken exclusions and unsafe config shapes. Recursive globs now use bounded matching, and excluded contextual files stay out of requests. [Norms tests](../src/engine/__tests__/norms.test.ts) · [Context tests](../src/engine/__tests__/bundler.test.ts)
- **P1** CI branch mismatch. Branch filters previously named `main`, while the published repository used `master`. CI now runs on both push and pull request events. [Workflow](../.github/workflows/ci.yml)

## D. Security review

The highest-risk boundaries are repository input to Git and the model, output from the model to the terminal and forge, and credentials to configured network clients. The implementation restricts local Git execution paths and context reads, validates structured findings, controls publication explicitly, and avoids recording provider response bodies. [Security policy](../SECURITY.md)

Open items include authorship checks for marker-driven note reuse and native pending reviews, stronger sanitization and secret detection for source excerpts, and a race window between the last head check and a multi-step publication. The full dependency audit reported 20 development advisories, including six high and zero critical.

## F. Compatibility

The local verification host was Windows with Node 24.16.0, npm 11.13.0 and Git 2.54.0.windows.1. The clean-install package test also passed on Windows with Node 22.12.0. Linux and macOS are configured for CI and await runs on those environments.
